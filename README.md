# MyBOT — Telegram Store Bot Based on aiogram

MyBOT is an educational Telegram bot project developed in Python using the aiogram framework. The project was created as a prototype of an online store inside Telegram, where users can browse products, interact with the catalog, and place orders through a convenient chat interface.

## Features

* User interaction through Telegram
* Product catalog management
* Navigation using inline and reply keyboards
* Order creation and processing
* Command handling system
* Database integration for storing products and user data
* Asynchronous request handling with aiogram

## Technologies Used

* Python
* aiogram
* SQLite / project database
* Telegram Bot API

## Project Purpose

The project was developed as a university assignment to explore:

* Telegram bot development
* Asynchronous programming
* API integration
* Backend application structure
* Database management

## Project Status

This project is a study prototype that demonstrates the basic implementation of a Telegram-based online store using aiogram.
